# NSCLC Delta Radiomics

Research code for PET/CT delta-radiomics analysis and exploratory machine-learning
classification of 2-year overall-survival status in non-small cell lung cancer (NSCLC).

> **Research status:** This repository is a research-code starter. The current notebooks
> require methodological revision before their harmonized predictive results can be
> interpreted as valid prospective prediction or used for clinical purposes. 

## Project overview

The notebooks implement an analysis workflow using paired pre-/post-treatment PET/CT
radiomic features. The workflow includes:

- PET and CT feature-table preparation;
- tumoral and peritumoral regions of interest;
- delta features calculated as post-treatment minus pre-treatment values (T2 − T1);
- scanner-batch grouping (GE versus non-GE);
- ComBat harmonization using `neuroHarmonize`;
- imputation, scaling, correlation filtering and recursive feature elimination (RFE);
- class-imbalance handling with SMOTE variants;
- machine-learning evaluation and supporting visualizations.

The main notebook documents repeated stratified 5-fold cross-validation with 10 repeats.
The supplementary notebook explores held-out splits and harmonized versus non-harmonized
analyses. The notebooks document the cohort and analysis decisions in more detail.

## Data

The source CSV is **not included** in this repository. The notebooks currently expect:

```text
radiomic_acrin_nsclc_dataset.csv
```

Place an authorized copy in the repository root (or update `RAW_CSV` in each notebook).
Do not commit patient-level data, identifiers, imaging files, clinical records, or any
data whose redistribution is not explicitly permitted. Follow the dataset provider's
access and citation requirements.

The held-out notebook also optionally reads `detailed_train_cv_metrics.csv` as a
reference file. This file is generated by the main notebook and is not included.

## Environment setup

Python version and exact dependency versions should be pinned after reproducing the
analysis in a clean environment.

```bash
python -m venv .venv
# Windows (PowerShell):
.venv\Scripts\Activate.ps1
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
jupyter lab
```

Open the notebooks in `notebooks/`. Run the main pipeline first. The held-out notebook
expects the source CSV and, for its CV reference comparison, the generated
`detailed_train_cv_metrics.csv` file.

## Important interpretation limits

- The cohort is small; estimates and confidence intervals must be interpreted cautiously.
- The held-out splits are partitions of the same cohort, not independent external
  validation cohorts.
- The current ComBat implementation includes the target label as a harmonization
  covariate. This makes the current harmonized prediction evaluation unsuitable for
  prospective prediction. See the technical review before interpreting results.
- This is research code, not a clinical decision-support tool.

## Reproducibility

The notebooks set random seeds and document their analysis steps. For a reproducible
release, record the Python/package versions, dataset version/accession and permitted
data provenance, and rerun the complete workflow from a clean environment after the
methodological issue in the technical review has been resolved.
